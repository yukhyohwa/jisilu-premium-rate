# 集思录折溢价率计算助手 (Jisilu Premium/Discount Helper)

油猴 (Tampermonkey) 脚本，自动在集思录 LOF 和 QDII 页面新增"折溢价率"列，无需登录也能看到实时计算结果。

## 适用页面

| 页面 | URL |
|------|-----|
| LOF 股票型 | https://www.jisilu.cn/data/lof/#stock |
| LOF 指数型 | https://www.jisilu.cn/data/lof/#index |
| QDII 基金 | https://www.jisilu.cn/data/qdii/ |

## 功能说明

脚本会在"基金净值"（LOF）或"T-2净值"（QDII）列的**右侧自动插入一列**，实时显示折溢价率百分比：

- 🔴 **红色正值** = 溢价（现价高于净值，市场价贵了）
- 🟢 **绿色负值** = 折价（现价低于净值，市场价便宜了）

## 计算公式

### LOF 基金
```
折溢价率 = (现价 - 基金净值) / 基金净值 × 100%
```

### QDII 基金（净值有延迟，需估算）
```
T-1 估算净值 = T-2净值 × (1 + T-1指数涨幅%)
折溢价率(估) = (现价 - T-1估算净值) / T-1估算净值 × 100%
```

> **为什么 QDII 要估算？**
> QDII 基金的官方净值通常延迟两天公布（T+2）。利用两天前的净值加上昨天跟踪指数的涨跌幅，可以近似估算出最新净值，再与今日现价对比，得出折溢价率。

## 安装方法

1. 安装 [Tampermonkey (篡改猴)](https://www.tampermonkey.net/) 浏览器扩展。
2. 在 Tampermonkey 管理面板中点击"**添加新脚本**"。
3. 将 `jisilu_premium_helper.user.js` 中的**全部代码**复制粘贴进去。
4. 按 `Ctrl + S` 保存。
5. 打开集思录相关页面，等待约 4 秒（数据异步加载），新列即出现。

## 注意事项

- **浏览器模式**：如果使用 360/QQ/搜狗浏览器，请确保切换为"**极速模式**"（Chromium 内核），兼容模式（IE 内核）不支持油猴脚本。
- **开发者模式**：在浏览器扩展管理页（`chrome://extensions`）需开启"**开发者模式**"，Tampermonkey 才能正常注入脚本。
- **等待时间**：集思录数据通过 Ajax 异步加载，脚本在页面载入 4 秒后才开始处理，之后每 6 秒刷新一次。
- **QDII 精度**：QDII 折溢价率为**估算值**，列标题标有"(估)"字样，实际结果以官方净值为准。
